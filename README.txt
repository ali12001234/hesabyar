حسابیار - نسخه قابل نصب PWA

برای نصب روی آیفون لازم است فایل‌های این پوشه را روی یک هاست HTTPS ثابت منتشر کنید (مثلاً GitHub Pages یا Cloudflare Pages). سپس لینک را در Safari باز کنید و Share > Add to Home Screen را بزنید. یک بار برنامه را با اینترنت باز کنید تا فایل‌های آفلاین ذخیره شوند. پس از آن برنامه می‌تواند آفلاین اجرا شود.

داده‌های مالی در IndexedDB همان دستگاه ذخیره می‌شوند، نه روی سرور. از داخل برنامه مرتباً خروجی پشتیبان JSON بگیرید و در Files نگهداری کنید. پاک کردن داده‌های Safari، حذف اپ یا تغییر دستگاه می‌تواند داده‌ها را از بین ببرد.

این نسخه برای استفاده آزمایشی است؛ قبل از ثبت اطلاعات مهم، ذخیره و بازیابی را با چند رکورد تست کنید.
